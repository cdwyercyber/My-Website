What Is a Computer Virus?

A computer virus is a type of malware that attaches itself to a normal file or program, and when that infected file is opened or run, the virus can activate and try to infect other files on the computer. Unlike worms, traditional computer viruses need a host file or program in order to spread.

Viruses can do different types of damage, such as corrupting files, changing system settings, stealing information, or interfering with how a computer normally works. Some viruses also have triggers that determine when they become active and begin carrying out their actions.

How Do Computer Viruses Work?

Viruses work by attaching their code to another file or program, and once that infected file is opened or run, the virus can start carrying out its instructions and try to create more infected copies.

Infection and Replication

The virus attaches itself to a host file and uses that file to run, and from there it may look for other files or programs that it can infect, allowing it to continue spreading throughout the computer.

Activation and Payload

Some viruses stay inactive until a certain condition is met, such as a specific date or something happening on the computer. Once the virus becomes active, it carries out its payload, which is just the action it was designed to perform.

Types of Computer Viruses

There are different types of computer viruses, and each one works a little differently depending on what it targets and how it spreads throughout a system.

File Infector Viruses

Attach themselves to program files and activate when someone opens or runs an infected program, allowing the virus to spread to other files on the computer.

Boot Sector Viruses

Infect parts of a storage device that are used when a computer starts up, allowing the virus to activate during the boot process and potentially affect the system.

Macro Viruses

Use macros in programs, like Microsoft Word and Excel, to infect documents, and can spread when those documents are shared with others and the macros are allowed to run.

Multipartite Viruses

Infect multiple parts of a computer, such as program files and boot sectors, which allows them to spread using different methods and affect more than one area of a system.

Polymorphic Viruses

Change parts of their code as they spread and create new copies, making it harder for antivirus software to recognize them because they don't always look the same.

How Do Viruses Spread?

Viruses spread when infected files are transferred between devices and executed, some examples being through:

  • Email attachments: Infected files or documents sent through email.
  • USB drives: Infected files transferred through removable storage.
  • Downloads: Malicious files obtained from untrusted websites.
  • File sharing: Infected files shared between users or computers.
  • Documents: Files containing malicious macros that execute when enabled.
